# 📄 PDF Chatbot using Gemini Pro & LangChain

An interactive Streamlit-based chatbot that lets users upload PDF documents, ask questions about their contents, and receive accurate, context-specific responses powered by **Gemini Pro** and **LangChain**.

---

## 🚀 Features

- 📥 Upload and process multiple PDF files
- 🔎 Extract and chunk PDF content using LangChain
- 🧠 Generate embeddings using Google Generative AI
- 🗂️ Store vectors in a FAISS vector database
- 💬 Answer user questions with Gemini Pro (ChatGoogleGenerativeAI)
- 💾 Save and load sessions
- 📝 Collect user feedback

---

## 🛠️ Tech Stack

| Technology               | Purpose                                         |
|--------------------------|-------------------------------------------------|
| Streamlit                | Web app interface                              |
| LangChain                | Text splitting, embeddings, and chaining       |
| Google Generative AI     | Embedding & chat model provider                |
| FAISS                    | Vector similarity search                       |
| PyPDF2                   | PDF parsing                                    |
| dotenv                   | Environment variable management                |
